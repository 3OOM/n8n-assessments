# Demo Video Script & Walkthrough Guide (Loom / YouTube)

> **Target Duration:** 60 – 90 seconds  
> **Tools:** Loom (recommended for quick share link), YouTube (Unlisted), or OBS  
> **Assessment Requirement:** All 6 key rubric criteria must be clearly demonstrated.

---

## 🎬 Step-by-Step Recording Timeline

| Timestamp | Screen Action | What to Say (Spoken Script) | Rubric Criterion Covered |
| :--- | :--- | :--- | :--- |
| **0:00 – 0:15** | Open n8n canvas. Point mouse at the top bar showing the workflow title. | *"Hello evaluator! In this video, I am demonstrating my submission for Topic 1: Create Your First Workflow. As you can see at the top of the canvas, the workflow is saved and named 'My First N8N Workflow'."* | Workflow setup and naming (10%) |
| **0:15 – 0:30** | Zoom/highlight the canvas layout. Point out the left-to-right connection line. | *"Here on the canvas, we have two nodes: our Manual Trigger ('When clicking Test workflow') connected with a directional arrow to our action node, 'Edit Fields (Set)'."* | Node selection & structure (20%) |
| **0:30 – 0:45** | Double-click the **Edit Fields (Set)** node to open its configuration modal. | *"Opening the Edit Fields node parameters, you can see under Fields to Set that we configured a String field named 'greeting' with the exact value 'Hello, n8n!'."* | Configuration accuracy (25%) |
| **0:45 – 1:00** | Close the modal. Click the **Test workflow** button at the bottom. | *"Now, I'll execute the workflow by clicking 'Test workflow'. Both nodes execute instantly with green checkmarks indicating zero errors."* | Execution success (25%) |
| **1:00 – 1:20** | Click on the **Edit Fields (Set)** output pane. Toggle between **Table**, **JSON**, and **Schema** views. | *"Looking at the output: in Table view we see the greeting column; in JSON view we have the exact JSON payload `{\"greeting\": \"Hello, n8n!\"}`; and in Schema view we confirm the string data type."* | Output inspection (25%) |
| **1:20 – 1:30** | Show the Save confirmation badge, show GitHub repository folder, and wrap up. | *"The workflow is saved and all files including the JSON export, README, and screenshots are organized in our public GitHub repository. Thank you!"* | Submission completeness (10%) |

---

## 📋 Pre-Recording Checklist

- [ ] Browser window zoomed to 100% or 110% for clear visibility of text and node titles.
- [ ] Workflow name visible as `My First N8N Workflow`.
- [ ] Edit Fields node configured with `greeting` = `Hello, n8n!`.
- [ ] No personal tokens or sensitive credentials exposed.
- [ ] Microphone tested and clear.
- [ ] Loom or YouTube link permissions set to **"Anyone with the link can view"** (Public / Unlisted).
